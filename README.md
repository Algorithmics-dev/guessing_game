# 🧠 Mind Reader Arena ⚡

Καλώς ήρθες στο Mind Reader Arena!

Σε αυτό το mini-game ο υπολογιστής διαλέγει έναν μυστικό αριθμό από το **1 μέχρι το 100** και εσύ πρέπει να τον ανακαλύψεις πριν τελειώσουν οι προσπάθειές σου.

Μετά από κάθε guess παίρνεις ένα hint:

* 🔥 **GO HIGHER!** αν ο μυστικός αριθμός είναι μεγαλύτερος
* 🧊 **GO LOWER!** αν ο μυστικός αριθμός είναι μικρότερος
* 🏆 **YOU FOUND IT!** αν βρεις τον σωστό αριθμό

Έχεις μόνο **7 attempts**. Μπορείς να διαβάσεις το μυαλό του υπολογιστή; 🧠

Το project είναι φτιαγμένο με **Python + PyQt5** και μπορείς να το αλλάξεις όπως θέλεις.

# 🔥 Remix Ideas

## Easy Remixes

* άλλαξε τα χρώματα του interface
* άλλαξε τα μηνύματα GO HIGHER και GO LOWER
* άλλαξε το range από 1–100 σε κάτι διαφορετικό

## Creative Remixes

* κάνε hacker password version
* κάνε treasure hunter version
* φτιάξε δικό σου arena theme

## Chaos Mode Ideas

* κάνε το range 1–10.000
* βάλε αστεία ή troll messages
* δώσε στον παίκτη μόνο 3 attempts

## Challenge Mode

* μπορείς να προσθέσεις κουμπί Restart;
* μπορείς να εμφανίζεις μήνυμα όταν ο παίκτης είναι πολύ κοντά στον αριθμό;
* μπορείς να κρατάς score ανάλογα με το πόσο γρήγορα βρίσκει τον αριθμό;

## Showcase

Αν κάνεις δικό σου remix στείλε μας το παιχνίδι (screenshot) στο κάναλι **Showcase** και μπορεί να δεις όνομα σου στο leaderboard.
